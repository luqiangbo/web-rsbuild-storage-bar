# StorageBar 隐私政策 · Privacy Policy

更新日期 / Last updated: 2026-11-22

## 简体中文

StorageBar 用于在 Chrome 中检查和管理你选择的网站标签页的浏览器存储。

**读取的数据。** 扩展读取当前打开的 HTTP 和 HTTPS 标签页标题及地址，用于显示目标列表。网站访问权限在安装时由 Chrome 请求。扩展按你使用的功能读取所选页面可访问的 LocalStorage、SessionStorage、IndexedDB、Cache Storage、未分区 Cookie，以及用于本地媒体预览的 OPFS 文件。部分站点数据和 Cookie 可能含有个人信息、登录会话或其他敏感内容。

**处理方式。** 数据在你的浏览器内用于展示、搜索、编辑、预览或清理。Web Storage 自动刷新开启时，扩展会在可见的 Web Storage 页面中刷新当前已授权目标的数据。只有你主动点击复制或导出时，扩展才会把所选内容写入剪贴板，或将 Cookie 备份交给浏览器下载。导入只读取你主动选择的本地文件，并在你确认后写入所选站点。

**存储、传输与共享。** StorageBar 在扩展的本地存储中保存语言、主题和密度等偏好。扩展不设接收存储数据的服务器，不会向开发者或第三方发送检查到的站点数据，也不会出售这些数据或用于广告。导出的 JSON 文件以及主动写入剪贴板的内容由你管理。Cookie 备份可能包含登录会话信息。

**你的控制。** 可在 Chrome 扩展管理页撤销站点访问权限，或卸载扩展以移除扩展本地偏好。此前导出的文件由你自行管理。对站点存储的编辑和清理会写入真实的浏览器存储。

**联系。** 请通过 StorageBar Chrome Web Store 页面上的支持渠道反馈隐私问题。

StorageBar 对通过 Google API 获得的信息的使用遵守 Chrome Web Store 用户数据政策，包括 Limited Use 要求。

## English

StorageBar lets you inspect and manage browser storage for a website tab you select in Chrome.

**Data accessed.** StorageBar reads the titles and addresses of open HTTP and HTTPS tabs to display the target selector. Chrome requests site access at installation. StorageBar reads the data needed for the feature you use from accessible LocalStorage, SessionStorage, IndexedDB, Cache Storage and unpartitioned cookies for the selected page. It can also read files from the site's origin-private file system for local media previews. Site storage and cookies can contain personal information, authentication sessions or other sensitive data.

**How data is used.** Chrome processes data on your device for inspection, search, editing, preview or cleanup. When Web Storage auto-refresh is enabled, StorageBar refreshes the current authorized target while the Web Storage view is visible. Copy and export actions send selected data to your clipboard or hand a Cookie backup to Chrome for local download. Import reads only the file you select and writes only after you confirm.

**Storage, transfer and sharing.** Preferences such as language, theme and density are stored locally in the extension. StorageBar has no server that receives inspected site data. It does not transfer that data to the developer or a third party, sell it, or use it for advertising. You control downloaded files and data you choose to copy. Cookie backup files may contain authentication sessions.

**Your controls.** You can revoke access to individual sites from Chrome's extension settings or uninstall the extension to remove its local preferences. Previously downloaded files are managed separately. Edit and cleanup actions you confirm change the actual site data stored in Chrome.

**Contact.** Use the support channel on StorageBar's Chrome Web Store listing for privacy questions.

StorageBar's use of information obtained through Google APIs complies with the Chrome Web Store User Data Policy, including the Limited Use requirements.
