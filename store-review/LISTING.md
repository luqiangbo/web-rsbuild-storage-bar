# StorageBar · 商店介绍

## 简体中文

**短描述**

在 Chrome 侧栏或独立标签页检查和管理当前网站的浏览器存储。

**详细介绍**

StorageBar 面向前端开发者和 QA。在 Chrome 安装时确认网站访问权限后，选择要检查的网页，即可在侧栏或独立工作台查看和管理站点存储。

- 搜索、查看和管理 LocalStorage、SessionStorage、IndexedDB、Cookies 和 Cache Storage。
- 在原文、格式化和树视图间查看 JSON，搜索键和值，复制节点及路径。
- 导出本站可访问的未分区 Cookie，或导入 StorageBar 的同站点本地 JSON 备份。导入前可预览新增、冲突及无效项。
- 预览已保存在当前网站浏览器存储中的可读视频。支持 OPFS、IndexedDB 和 Cache Storage 中 Chrome 可解码的完整视频，单条预览上限 50 MiB。
- 支持简体中文和英文、浅色和深色、跟随系统及不同列表密度。

StorageBar 的存储检查和预览都在本机完成。Cookie 备份由你主动导出，其中可能包含登录会话信息。清理操作会先显示目标和范围供你确认。

## English

**Short description**

Inspect and manage a website's browser storage in the Chrome side panel or a dedicated workspace tab.

**Detailed description**

StorageBar is a browser storage inspector for frontend developers and QA. After accepting Chrome's site access prompt at installation, choose the page you want to inspect in the side panel or a dedicated workspace tab.

- Search, inspect and manage LocalStorage, SessionStorage, IndexedDB, Cookies and Cache Storage.
- View JSON as raw text, formatted text or a tree. Search keys and values, and copy nodes and paths.
- Export accessible unpartitioned cookies for the selected site or import a same-site StorageBar JSON backup. Preview new entries, conflicts and invalid entries before writing.
- Preview videos that the current site already stores in OPFS, IndexedDB or Cache Storage. Complete, readable videos must be playable by Chrome and may be up to 50 MiB per preview.
- Choose English or Simplified Chinese, follow the system appearance or select light or dark mode, and adjust table density.

Storage inspection and video preview happen locally. Cookie backups are created when you request an export and may include session information. Cleanup dialogs show the target and affected scope for confirmation.
