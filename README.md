# StorageBar

Chrome Manifest V3 侧边栏扩展，用于检查和管理当前网页的 IndexedDB、Cookies、LocalStorage、SessionStorage 与 Cache Storage。

## 开发

```powershell
pnpm install
pnpm dev
```

扩展打包入口由 Rsbuild 生成到 `dist`，Chrome 扩展清单位于 `public/manifest.json`。

## 首次使用

1. 在 Chrome 扩展管理页启用开发者模式，并加载构建后的 `dist` 目录。
2. 打开要管理的 HTTP/HTTPS 网页，再点击 StorageBar 扩展图标打开侧边栏。
3. 按 Chrome 提示确认安装时的网站访问权限。若曾在 Chrome 限制站点访问，可从扩展详情更改权限。
4. 用站点选择框左侧的数据库和摄像机图标切换「本地存储」和「本地媒体」。「本地存储」里可选择存储分类，点击表格行可在宽弹窗查看、编辑和复制。「本地媒体」直接在下方工作区显示目录和预览。

当前支持普通 HTTP 或 HTTPS 网页的顶层文档。Chrome 内部页面、扩展页面和浏览器限制的页面不能读取。Cookie 列表显示当前标签页 Cookie 存储区中已授权的相关未分区 Cookie。SessionStorage 的作用范围为目标标签页。

## Cookie 备份与本地媒体

- 在 Cookies 分区点击导入或导出图标，管理同站点的 StorageBar JSON 备份。导入前会列出新增、冲突和无效项，默认跳过冲突。备份包含 Cookie 原值，应保存在信任的位置。
- 在「本地媒体」中用面包屑或目录树浏览 OPFS、IndexedDB 和 Cache。列表为可见的小图片和小视频显示缩略图，OPFS 支持图片、音频和视频预览。IndexedDB 展示对象仓库中的视频，Cache 展示可识别的视频响应。当前页会选中首个可预览文件，已知不超过 8 MiB 的文件自动加载，音频和视频由用户启动。大文件可手动加载，单个预览上限为 50 MiB。

## 独立工作台与 JSON

- 点击侧栏顶部的「在新标签页打开」。工作台继承目标网页和当前分类，并锁定目标。目标关闭后，请从顶部重新选择。刷新工作台会保留选中的目标和分类。
- 侧栏和工作台共享语言、主题和密度。布局按容器宽度调整，600px 起展示更多表格信息，960px 起可在详情中点击图钉，将详情固定到表格右侧。
- JSON 详情直接显示格式化结果，保留原始数字文本。「前后对比」可切换到原文或结构树。CodeMirror 编辑区提供行号、折叠、括号匹配、查找替换和保存前预览。
- 记录行与 JSON 节点都可通过右键、「⋯」或 `Shift+F10` 打开菜单。记录菜单可查看详情、复制或进入删除确认，节点菜单可复制键、原始值和 JSON Pointer 路径。
- Web Storage 支持记录基线并对比当前变化、导入导出原始键值，以及撤销近一次批量删除。跨站导入会展示来源与目标，并要求明确确认。
- IndexedDB 支持精确主键、主键范围和索引查询。Cookie 可粘贴 Cookie-Editor JSON 或旧版 StorageBar 备份，也可复制或下载 JSON。设置中的「数据字体」应用到键值、路径和 JSON 编辑器。

## 快速验收

加载包含最新修改的扩展产物后，在 300px 和 500px 的侧栏宽度检查搜索、详情和键盘焦点。在测试网站新增并编辑一条 LocalStorage 记录，刷新后重新打开详情。打开编辑表单后切换到另一个标签页，确认旧草稿仍可复制且保存停用。最后在测试网站取消一次清理，确认数据未变化。再次确认清理时核对五类结果与页面读回数据。

用一个测试站点创建同名、不同路径的 Cookie，导出后立即导入一次，确认默认跳过冲突。删掉其中一条后再导入，核对新增和跳过的逐项结果。打开在 OPFS、IndexedDB 或 Cache Storage 保存过 MP4 或 WebM 的测试站点，检查侧栏及独立窗口播放，切页后确认旧目标预览关闭或失效。

打开两个同源标签页，为 SessionStorage 写入不同标记。从其中一页打开工作台，切到另一个标签页后确认工作台仍读取原标记。把工作台调整到 600px 和 960px 两侧，核对列数和固定详情。分别切换语言与主题，检查侧栏、工作台和独立预览。用含有 `9007199254740993` 的 JSON 验证格式化、复制和 Web Storage 原文都保留原数字。
